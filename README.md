# whosimply

A minimalist decision tool.

## Usage

Paste names separated by lines. You can also use commands:

- `split [number]` to group names into the specified number of groups.
- `pick [number]` to select the specified number of winners.

This is a page from the pageShyt [collection](https://pageshyt.vercel.app).

## Setup

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
